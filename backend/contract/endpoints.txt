# API contract: every endpoint the clients call.
#
# One line per call:   <client> <METHOD> <path under /api/v1> [| expected-fail: <reason>]
#   client  = app (Flutter) or admin (Next.js)
#   {id}    = any id segment
#   Query-parameter lines look like:  app GET /hostels/?search
#
# apps/core/test_contract.py resolves every path with django.urls.resolve and checks the
# view allows the method. A line without a marker that fails breaks the build (a route was
# renamed or removed). A line WITH a marker that now passes also breaks the build: delete
# the marker in the same change that fixes the route.
#
# Keep in step with the clients: the app repo checks its own copy
# (rohii_hostel_hunt/test/contract/app_endpoints.txt) against the Dart sources.
